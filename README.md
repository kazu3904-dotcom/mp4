# かんたん動画カッター

MOV / MP4 / WebM / MKV / 3GP などの動画を、必要な範囲だけ切り出して **MP4** で保存するブラウザアプリです。

**使い方**: https://kazu3904-dotcom.github.io/mp4/ を開き、動画をドラッグ＆ドロップして範囲を決め、「MP4として保存」を押します。

## プライバシー
動画はお使いの端末のブラウザ内だけで処理され、サーバーや GitHub には送信されません。アクセス解析や広告も使っていません。

## 保存方式
- **高速モード**: 再エンコードなし。短時間で完了し、画質は劣化しません。開始位置が直前のキーフレームにずれることがあります。非対応の形式は自動で再エンコードします。
- **正確モード**: 再エンコードして 1 フレーム単位で切り出します。時間がかかります。

## 注意事項
- 数 GB を超える大きな動画や特殊な形式は、ブラウザのメモリ不足などで失敗することがあります。
- 他人の動画や著作物を扱う場合は、著作権などの権利に注意してください。利用は自己責任でお願いします。
- 本ソフトウェアは現状有姿で提供され、動作や結果について一切の保証はありません。

## 使用しているオープンソース
- [ffmpeg.wasm](https://github.com/ffmpegwasm/ffmpeg.wasm)（`@ffmpeg/ffmpeg` / `@ffmpeg/core`）: 動画の変換に使用しています。変換エンジン（`@ffmpeg/core`）はアプリ起動時に CDN（jsDelivr）から読み込んでおり、このリポジトリには含めていません。
- [FFmpeg](https://ffmpeg.org/)（LGPL/GPL）および [x264](https://www.videolan.org/developers/x264.html)（GPL）: ffmpeg.wasm の中で利用されています。各ライセンスの詳細は、それぞれのプロジェクトのページを参照してください。

`vendor/` 内の `ffmpeg.js` と `814.ffmpeg.js` は `@ffmpeg/ffmpeg` 0.12.10 の配布ファイル（MIT License）です。
